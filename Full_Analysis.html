What the data shows

  • Value is concentrated in the Loans service group. It contributes 72.92% of successful payment value with one sixth of attempts. The source group also includes Mutual Fund and Credit Score; its value cannot be treated as verified lending principal.
  • Money Transfer drives volume. It has 150,000 attempts, exactly half of the dataset. High volume and high value are different operating priorities.
  • 12,007 attempts were unsuccessful. Their attempted value is ₹14.13 Cr. This is an amount attached to unsuccessful attempts, not demonstrated financial loss. There is no retry or settlement linkage.
  • Daily use is nearly even across the week. Weekdays hold 71.60% of attempts, but only 0.48% more attempts per calendar day than weekends. More weekday dates explain almost all of the total-count gap.
  • Join dates need correction before lifecycle analysis. 162,399 attempts (54.13%) occur before the recorded join date, affecting 65,062 users. Acquisition, tenure and signup-based retention conclusions would be unreliable.

How the package was built

The semantic model joins Users → Transactions ← Calendar with single-direction filters. All original records are retained. Text is trimmed, service underscores are replaced with spaces for display, dates and amounts receive explicit types, and normalized outcomes, age bands and join-date flags are added. Monetary reconciliation uses integer cents; the Power BI model uses fixed-decimal amounts.

The revised native report contains six pages, 83 visuals and 31 DAX measures. It imports three prepared CSV files using the DataFolder parameter; each table loads independently. Age bands, normalized outcomes and join-date flags are prepared in these CSV snapshots before import. Month, outcome, service and age slicers apply where present. Page selections are local to each page. Success rate follows the selected outcome context: choosing only Successful makes the rate 100%; clear the outcome selection for overall reliability. Static text and this analysis describe the supplied snapshot and must be reviewed if the source changes.

Validation boundary: Source totals, CSV snapshots, relationships by ID, visual field references, report schemas and ZIP integrity were checked. The previous embedded-query package failed to refresh in the user’s Power BI Desktop. The exact cause of the reported domain error is unconfirmed. This revision removes those embedded queries and corrects the background-image reference. Power BI Desktop is not available in this environment, so the revised refresh, DAX execution and native rendering still need verification in Desktop. Dashboard_Preview.png is a design render with the source figures, not a screenshot from Power BI.

Source workbook: Source/Phonepe-Final-Dataset.xlsx, an unchanged copy of the uploaded workbook. Branding: supplied asset ZIP. Layout reference: supplied screenshot. Detailed reproducible summaries: the CSV files and Analysis.json in this folder. Monetary CSV columns ending in _cents contain integer hundredths of the assumed currency unit; divide by 100 for rupees or by 1,000,000,000 for crore.
